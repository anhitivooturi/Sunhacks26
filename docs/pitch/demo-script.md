# 3-minute demo script

| Time | Who | Say / do |
|---|---|---|
| 0:00 | Person D | "Every TA knows this moment: the professor says 'base case' and half the room is gone, silently. Wait, what? is the TA's ear for the whole hall." (title slide, Pip) |
| 0:15 | Person C | Click **Start session** on the projector. "One click. Here's the code and QR." |
| 0:25 | Judges | "Scan this. No login." Phones open, 4 buttons. Show the anonymous line. |
| 0:40 | Person D | "One tap. No scrolling, nothing to read." Tap Lost. Point out buzz + 3-second ring. |
| 0:55 | Person C | Meter on screen: "Calm, not flashing. Professor keeps teaching." Live transcript scrolling. |
| 1:10 | Person A | Run `fake-class.js` with the spike: "Here's a class that just lost the thread." Meter climbs to amber/red. |
| 1:35 | Person C | **End session** -> report. "Detect." Timeline strip, moment marker at 2:36. |
| 1:50 | Person C | Open the moment. "Explain." Highlighted quote, label *Undefined term*, "14 of 20 lost", confidence high. |
| 2:10 | Person C | "Fix." Re-explanation, example, quiz. Tap **Push to phones**. |
| 2:20 | Person D | Phone buzzes, fix sheet appears. Answer the quiz live. |
| 2:40 | Person C | "Verify." Before/after: "70% lost, then 80% answered correctly." |
| 2:50 | Person D | Show the student's "You were lost here" review, tap Concept diagram. "Everyone leaves with notes in the format they learn best." |
| 3:00 | All | "Detect. Explain. Fix. Verify. Wait, what?" Hand over evidence slide. |

Backup: if Wi-Fi dies, `?mock=1` runs the whole phone flow on fixtures; Person A's `load-seed.js` has the seeded report.
